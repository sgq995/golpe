# Summary

The generator turns the AST from [SPEC-001](/specs/001-template-language.md)
into ordinary Go. Each template becomes a function that returns a
[golpe.Element](/entities/element.md), a writer function the developer can
call, pass around and compose without any Golpe API.

# Motivation

- Plain functions are easy to understand, debug and test; there is no
  framework at runtime beyond a few escaping helpers.
- Checking every write error lets callers stream into any `io.Writer`
  (`http.ResponseWriter`, `bytes.Buffer`, a gzip writer) and stop on the
  first failure.
- Escaping by default prevents XSS. The example in the original feature
  description wrote `fmt.Fprintf(w, `<a href="%v">`, props.Route)`; that
  must never be the output.
- Line directives keep compiler errors pointing at what the developer wrote.

# Requirements

- **R1 One file per source.** `dir/x.golpe` MUST produce `dir/x_golpe.go`
  in the same package, starting with `// Code generated by golpe. DO NOT EDIT.`
  and keeping the source's build constraints.
- **R2 Pass-through.** Go outside templates MUST be emitted unchanged
  (modulo gofmt), including comments and doc comments.
- **R3 Template signature.** `template Name[TP](params)` MUST become
  `func Name[TP](params) golpe.Element`, returning a closure
  `func(w io.Writer) error` whose body is the template body; the closure
  ends with `return nil`. Doc comments carry over.
- **R4 element.** References to the predeclared `element` MUST become
  `golpe.Element`.
- **R5 Static HTML.** Tags, attributes with static values and text MUST be
  written with their final bytes computed at generation time; adjacent static
  bytes MUST be coalesced into a single write.
- **R6 Error propagation.** Every write and every Element call MUST be
  checked; the first error is returned immediately.
- **R7 Escaping.** Text interpolations MUST be HTML-escaped (`&`, `<`, `>`,
  `"`, `'`); attribute interpolations MUST be attribute-escaped and
  double-quoted; Elements are rendered unescaped (they escape their own
  content). Static text is escaped at generation time.
- **R8 Embedded statements** MUST lower to the same Go statement with the same
  header, and lowered markup bodies.
- **R9 Hygiene.** Generated identifiers (writer, imports, temporaries) MUST use
  the reserved `__golpe` prefix so they cannot collide with user code.
- **R10 Positions.** Every piece of user Go code MUST be preceded by a
  `/*line file.golpe:L:C*/` directive so `go build`/`go vet` report `.golpe`
  positions.
- **R11 Determinism.** The same input MUST produce byte-identical,
  `gofmt`-clean output.
- **R12 Dependencies.** Generated code MUST import only the standard library
  and `github.com/sgq995/golpe`.

# Examples

Input: the `NavItem` example from [SPEC-001](/specs/001-template-language.md).
Output (directives elided for readability):

```go
// Code generated by golpe. DO NOT EDIT.

package nav

import __golpe "github.com/sgq995/golpe"

func NavItem(props NavItemProps) __golpe.Element {
	return func(__golpeW __golpe.Writer) error {
		if err := __golpe.WriteString(__golpeW, "<li>"); err != nil {
			return err
		}
		if props.Selected {
			if err := __golpe.WriteString(__golpeW, "<span>"); err != nil {
				return err
			}
			if err := __golpe.Write(__golpeW, props.Children); err != nil {
				return err
			}
			if err := __golpe.WriteString(__golpeW, "</span>"); err != nil {
				return err
			}
		} else {
			if err := __golpe.WriteString(__golpeW, "<a href="); err != nil {
				return err
			}
			if err := __golpe.WriteAttr(__golpeW, props.Route); err != nil {
				return err
			}
			if err := __golpe.WriteString(__golpeW, ">"); err != nil {
				return err
			}
			if err := __golpe.Write(__golpeW, props.Children); err != nil {
				return err
			}
			if err := __golpe.WriteString(__golpeW, "</a>"); err != nil {
				return err
			}
		}
		if err := __golpe.WriteString(__golpeW, "</li>"); err != nil {
			return err
		}
		return nil
	}
}
```

(`__golpe.Writer` is an alias of `io.Writer`, so the generated file needs no
`io` import that could clash with the user's.)

The user then writes ordinary Go:

```go
err := NavItem(NavItemProps{Route: "/docs", Children: Text("Docs")})(w)
```

# Acceptance criteria

- [ ] Golden tests: every example in SPEC-001 generates the checked-in
      `*_golpe.go` exactly, and that output compiles and renders the expected
      HTML.
- [ ] `{"<script>"}` renders `&lt;script&gt;`; `href={"\"onmouseover=x"}`
      renders `href="&#34;onmouseover=x"`.
- [ ] A writer that fails on the Nth write makes the template return that
      error and stop writing.
- [ ] A type error in an interpolation is reported by `go build` at the
      `.golpe` line and column.
- [ ] Generating twice yields identical bytes; `gofmt -l` reports nothing.

# Out of scope

- Type-directed lowering (calling Elements directly instead of through
  `__golpe.Write`); see [DEC-004](/decisions/004-runtime-dispatch-for-interpolation.md).
- Minifying HTML.
