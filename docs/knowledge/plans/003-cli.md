# Approach

Implements [SPEC-003](/specs/003-cli.md) in `cmd/golpe` (renamed from
`cmd/cli` so `go install` and `go tool` name the binary `golpe`) with the
standard `flag` package only. `run(args, stdout, stderr) int` already exists
and is unit-testable. The real work lives in `internal/build` so the
[language server](/actuators/language-server.md) can reuse it.

# Architecture

```text
cmd/golpe/main.go      run(): dispatch "generate" | "version" | "help" (| "lsp" later)
cmd/golpe/generate.go  flags: -check, -clean=true, -j N; prints diagnostics
internal/build         Expand(patterns) []string; GenerateFile(path) (Result, error)
```

func GenerateFile(path string, resolve generator.Resolver) (Result, error) {
	src, err := os.ReadFile(path)
	if err != nil {
		return Result{}, err
	}
	fset := token.NewFileSet()
	f, err := parser.ParseFile(fset, filepath.Base(path), src)
	if err != nil {
		return Result{}, err // scanner.ErrorList: file:line:col
	}
	out, err := generator.Generate(fset, f, src, resolve)
	if err != nil {
		return Result{}, err
	}
	target := filepath.Join(filepath.Dir(path), generator.GeneratedName(filepath.Base(path)))
	old, _ := os.ReadFile(target)
	return Result{Target: target, Output: out, Changed: !bytes.Equal(old, out)}, nil
}

// IsGolpeGenerated reports whether the first line is golpe's header, so

Workers: a pool of `runtime.GOMAXPROCS(0)` goroutines using only `sync`;
results indexed by input order, diagnostics printed sorted.

# Testing

- `cmd/golpe`: `run` table tests (exist for version/help).
- `internal/build`: `Expand` over a `testdata` tree; `GenerateFile` in a temp
  dir; `-check`, `-clean` (only golpe-headed orphans) and mtime stability.
- End-to-end: `run([]string{"generate", dir}, …)` over a copied `testdata`
  module.
