# Actors
People and external systems that interact with Golpe.

* [Developer](developer.md) - a Go programmer who writes .golpe files and uses the generated functions
* [Maintainer](maintainer.md) - the project owner who describes features and approves specs, plans and decisions
* [AI agent](ai-agent.md) - a coding agent that writes the knowledge base and implements task slices
* [Go toolchain](go-toolchain.md) - the go command and compiler that consume generated Go
* [Editor](editor.md) - an LSP client used to edit .golpe files
* [gopls](gopls.md) - the Go language server, run as a subprocess by Golpe's language server
