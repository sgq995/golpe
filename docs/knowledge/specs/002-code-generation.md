# Summary

The generator turns the AST from [SPEC-001](/specs/001-template-language.md)
into ordinary Go that depends **only on the standard library**
([DEC-005](/decisions/005-standard-library-only-output.md)). A project using
Golpe needs the CLI ([SPEC-003](/specs/003-cli.md)) and nothing else: no
golpe import, no runtime.

# Motivation

- **Plain functions** are easy to read, debug and test; there is nothing to
  learn at runtime.
- **Standard library only** keeps Golpe optional: the generated files are
  committed, so `go build` and `go get` work without the CLI, and a project
  can stop using Golpe and keep the generated code.
- **Escaping by default** prevents XSS
  ([DEC-009](/decisions/009-escape-by-default.md)). The original sketch wrote
  `fmt.Fprintf(w, `<a href="%v">`, props.Route)`, which is an injection hole.
- **Checked writes** let callers stream into any `io.Writer`
  (`http.ResponseWriter`, `bytes.Buffer`, gzip) and stop at the first failure;
  errors name the `.golpe` position so a failure deep in a page is traceable.
- **Line directives** keep compiler errors pointing at what the developer
  wrote.

# Requirements

## Files

- **R1 One file per source.** `dir/name.golpe` MUST produce `dir/name_gen.go`
  in the same package. `_gen` goes before Go's file-name suffixes so they keep
  working: `name_test.golpe` → `name_gen_test.go`,
  `name_linux_amd64.golpe` → `name_gen_linux_amd64.go`.
- **R2 Header.** The first line MUST be
  `// Code generated by golpe. DO NOT EDIT.`, matching Go's convention
  (`^// Code generated .* DO NOT EDIT\.$`). Build constraints of the source
  are copied.
- **R3 Committed.** Generated files are meant to be committed; `golpe generate
  -check` detects stale ones (SPEC-003).
- **R4 Standard library only.** Generated code MUST import only standard
  library packages (`fmt`, `html`, `io`, as used) and never
  `github.com/sgq995/golpe`. An import the source already has for the same
  path is reused; a missing one is added under its default name, or under a
  `__golpe`-prefixed alias when that name is taken.

## Declarations

- **R5 Pass-through.** Go outside templates MUST be emitted unchanged (modulo
  gofmt), comments and doc comments included.
- **R6 Template signature.** `template Name[TP](params)` MUST become
  `func Name[TP](params) func(io.Writer) error`, returning a closure
  `func(__golpeW io.Writer) error` whose body is the lowered template body,
  ending with `return nil`. Doc comments carry over.
- **R7 Predeclared names.** `element` MUST become `func(io.Writer) error`;
  `writer()` MUST become the closure's writer. Shadowed names are left alone.

## Markup

- **R8 Static output.** Tags, static attributes and text MUST be written
  verbatim (after the whitespace rule of SPEC-001 R22); a self-closing
  non-void element is written as `<x …></x>` (HTML ignores `/>` there, so
  `<script/>` would swallow the page) and a void element as `<x …>`, with
  adjacent static
  bytes coalesced into one `io.WriteString`, also across consecutive markup
  statements with no Go code between them.
- **R9 Values.** A value interpolation `{x}` MUST evaluate `x` once; a nil
  interface writes nothing; anything else writes
  `html.EscapeString(fmt.Sprint(x))`.
- **R10 Render calls.** An interpolation containing `writer()` MUST become
  `if err := <expr>; err != nil { return … }`. A render expression that is not
  a single `error` is a Go compile error, reported at the `.golpe` position.
- **R11 Dynamic attributes** MUST be lowered with plain `if` statements on the
  value evaluated once: `true` writes ` name`; `false` and `nil` write nothing;
  anything else writes ` name="` + escaped `fmt.Sprint` + `"`.
- **R12 Embedded statements** MUST lower to the same Go statement with the same
  header and lowered bodies.
- **R13 Errors.** Every write and render call MUST be checked; the first error
  is returned immediately, wrapped as
  `fmt.Errorf("file.golpe:line:col: Template: %w", err)` with the position of
  the failing write or call. Errors from the user's own `return err` pass
  through unchanged. `errors.Is`/`errors.As` keep working.

## Quality

- **R14 Hygiene.** Generated identifiers (writer, temporaries, import aliases)
  MUST use the reserved `__golpe` prefix.
- **R15 Positions.** Every piece of user Go code MUST be preceded by a line
  directive so `go build`/`go vet` report `.golpe` positions (LAB-006/007).
- **R16 Determinism.** The same input MUST produce byte-identical,
  gofmt-clean output.
- **R17 Performance.** Standard-library performance is accepted:
  `fmt.Sprint` and `html.EscapeString` per value. Type-aware lowering is a
  later optimization that must produce identical bytes ([backlog](/backlog.md)).

# Example

Input: the `NavItem` example of SPEC-001. Output (line directives elided,
positions illustrative):

```go
// Code generated by golpe. DO NOT EDIT.

package nav

import (
	"fmt"
	"html"
	"io"
)

func NavItem(props NavItemProps) func(io.Writer) error {
	return func(__golpeW io.Writer) error {
		if _, err := io.WriteString(__golpeW, "<li>"); err != nil {
			return fmt.Errorf("nav.golpe:4:2: NavItem: %w", err)
		}
		if props.Selected {
			if _, err := io.WriteString(__golpeW, "<span>"); err != nil {
				return fmt.Errorf("nav.golpe:6:3: NavItem: %w", err)
			}
			if err := props.Children(__golpeW); err != nil {
				return fmt.Errorf("nav.golpe:6:10: NavItem: %w", err)
			}
			if _, err := io.WriteString(__golpeW, "</span>"); err != nil {
				return fmt.Errorf("nav.golpe:6:36: NavItem: %w", err)
			}
		} else {
			if _, err := io.WriteString(__golpeW, "<a"); err != nil {
				return fmt.Errorf("nav.golpe:8:3: NavItem: %w", err)
			}
			if __golpeV := any(props.Route); __golpeV == true {
				if _, err := io.WriteString(__golpeW, " href"); err != nil {
					return fmt.Errorf("nav.golpe:8:6: NavItem: %w", err)
				}
			} else if __golpeV != false && __golpeV != nil {
				if _, err := io.WriteString(__golpeW, ` href="`+html.EscapeString(fmt.Sprint(__golpeV))+`"`); err != nil {
					return fmt.Errorf("nav.golpe:8:6: NavItem: %w", err)
				}
			}
			if _, err := io.WriteString(__golpeW, ">"); err != nil {
				return fmt.Errorf("nav.golpe:8:24: NavItem: %w", err)
			}
			if err := props.Children(__golpeW); err != nil {
				return fmt.Errorf("nav.golpe:8:26: NavItem: %w", err)
			}
			if _, err := io.WriteString(__golpeW, "</a>"); err != nil {
				return fmt.Errorf("nav.golpe:8:51: NavItem: %w", err)
			}
		}
		if _, err := io.WriteString(__golpeW, "</li>"); err != nil {
			return fmt.Errorf("nav.golpe:10:2: NavItem: %w", err)
		}
		return nil
	}
}
```

The developer then writes ordinary Go:

```go
err := NavItem(NavItemProps{Route: "/docs", Children: docsLabel})(w)
```

# Acceptance criteria

- [ ] Golden tests: every SPEC-001 example generates the checked-in
      `*_gen.go` exactly; the output compiles and renders the expected HTML.
- [ ] Generated files import nothing outside the standard library.
- [ ] `{"<script>"}` renders `&lt;script&gt;`; `href={"\"onmouseover=x"}`
      renders `href="&#34;onmouseover=x"`; `&nbsp;` in static text stays
      `&nbsp;`.
- [ ] `disabled={false}` omits the attribute; `disabled={true}` writes
      ` disabled`; `{err}` with a nil error writes nothing.
- [ ] A writer failing on the Nth write makes the template return that error,
      wrapped with the `.golpe` position, and stop writing.
- [ ] A type error in an interpolation is reported by `go build` at the
      `.golpe` line and column.
- [ ] `name_test.golpe` produces `name_gen_test.go`.
- [ ] Generating twice yields identical bytes; `gofmt -l` reports nothing.
