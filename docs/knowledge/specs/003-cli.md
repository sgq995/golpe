# Summary

`golpe` is the only thing a project needs to use Golpe: generated code depends
on the standard library alone ([SPEC-002](/specs/002-code-generation.md)).
`golpe generate` compiles `.golpe` files into `_gen.go` files; `golpe lsp`
comes later ([SPEC-004](/specs/004-language-server.md)).

# Motivation

Fit Go's habits: install it like any Go tool, run it from anywhere in a
module with `./...` patterns or from `//go:generate`, and fail CI when someone
forgot to regenerate.

# Requirements

- **R1 One binary.** The CLI lives in `cmd/golpe`, so it installs as `golpe`:
  `go install github.com/sgq995/golpe/cmd/golpe@latest`, or as a module tool
  (`go get -tool github.com/sgq995/golpe/cmd/golpe`, then `go tool golpe`).
- **R2 generate.** `golpe generate [patterns]` MUST generate every `.golpe`
  file matched; patterns are directories, files or `dir/...`; default `./...`.
  `vendor/`, `testdata/` and directories starting with `.` or `_` are skipped,
  as `go` does.
- **R3 Write if changed.** A generated file is written only when its content
  changes, keeping mtimes stable for build caches and watchers.
- **R4 Diagnostics.** Errors MUST be printed one per line as
  `path.golpe:line:col: message`, paths relative to the working directory,
  sorted; the exit code is 1 if any file failed, and the other files are
  still generated.
- **R5 -check.** `golpe generate -check` MUST write nothing and exit 1, listing
  the stale files, when any generated file is missing or out of date.
- **R6 Orphans.** With `-clean` (default on), a `_gen.go` file whose first line
  is golpe's header and whose `.golpe` source is gone MUST be removed. Files
  from other generators are never touched.
- **R7** `golpe version` and `golpe help` work; unknown commands exit 2 with
  usage on stderr. *(Done in the scaffold.)*
- **R8** Files SHOULD be generated in parallel; output stays deterministic.

# Acceptance criteria

- [ ] `golpe generate ./...` in a fixture module produces the golden files.
- [ ] A syntax error in one file prints `a.golpe:3:5: …`, exits 1, and the
      other files are still generated.
- [ ] `golpe generate -check` exits 0 right after generation and 1 after a
      `.golpe` edit.
- [ ] Running generate twice does not change mtimes.
- [ ] `go tool golpe version` works in a module that added the tool.
