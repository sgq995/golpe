# Approach

Implements [SPEC-003](/specs/003-cli.md) in `cmd/cli` with the standard
`flag` package only (no Cobra): `run(args, stdout, stderr) int` already exists
and is unit-testable. The real work lives in `internal/build` so the
[language server](/actuators/language-server.md) can reuse it.

# Architecture

```text
cmd/cli/main.go        run(): dispatch "generate" | "version" | "help" (| "lsp" later)
cmd/cli/generate.go    flags: -check, -clean=true, -j N; prints diagnostics
internal/build         Expand(patterns) []string; GenerateFile(path) (out []byte, changed bool, err)
```

# Snippets

```go
// internal/build
func Expand(root string, patterns []string) ([]string, error) // "./..." → all *.golpe, skipping vendor, testdata, ., _

func GenerateFile(path string) (Result, error) {
	src, err := os.ReadFile(path)
	if err != nil {
		return Result{}, err
	}
	fset := token.NewFileSet()
	f, err := parser.ParseFile(fset, filepath.Base(path), src)
	if err != nil {
		return Result{}, err // scanner.ErrorList: file:line:col
	}
	out, err := generator.Generate(fset, f, src)
	if err != nil {
		return Result{}, err
	}
	target := strings.TrimSuffix(path, ".golpe") + "_golpe.go"
	old, _ := os.ReadFile(target)
	return Result{Target: target, Output: out, Changed: !bytes.Equal(old, out)}, nil
}
```

Workers: `errgroup`-style pool with `runtime.GOMAXPROCS` workers using only
`sync`; results collected into a slice indexed by input order, then printed
sorted (R7).

# Testing

- `cmd/cli`: `run` table tests (exists for version/help).
- `internal/build`: `Expand` over a `testdata` tree; `GenerateFile` with a
  temp dir; `-check` and mtime-stability tests use `os.Chtimes` and compare.
- End-to-end: table tests that run `run([]string{"generate", dir}, …)` over
  a copied `testdata` module. (txtar script tests would need
  golang.org/x/tools; not worth a dependency yet.)
